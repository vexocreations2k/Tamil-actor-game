CHENNAI STREET LEGENDS - MINI GAME

This is a small original GTA-style top-down driving prototype, not the full GTA 5 game.

HOW TO PLAY
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to play in a modern web browser.
4. Press Start / Restart.
5. Use Arrow keys or WASD on a keyboard.
6. On a phone, open index.html in a browser and use the on-screen buttons.
7. Collect stars and avoid the police cars.

FILES
- index.html: game page
- style.css: design
- game.js: game logic

This fan-made prototype uses simple original graphics and is not affiliated with Rockstar Games or any actor/film franchise.
